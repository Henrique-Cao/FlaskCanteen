# 🍱 Canteen Order Rail

> A high-contrast, accessible Digital Kitchen Display & Order Management System designed for low-tech literacy and fast-paced kitchen environments.

---

## 📸 Overview & Key Features

Canteen Order Rail replaces traditional paper order tickets with a streamlined, digital display rail. Built specifically to eliminate cognitive load in chaotic kitchen environments, it features high-contrast visuals and one-tap order progression.

* **🎯 Touch-First KDS (Kitchen Display System):** Large visual targets, high-contrast states, and single-tap order completion tailored for rapid kitchen workflows.
* **⚡ Flask Blueprints Architecture:** Modular backend structure cleanly separating kitchen display logic, order intake, and administration.
* **🗃️ Lightweight Persistence:** Optimized SQLite database layer ensuring fast local reads/writes with zero infrastructure overhead.
* **🎨 Accessible & Responsive UI:** Built with utility-first CSS for crisp scannability and mobile-first responsiveness.
